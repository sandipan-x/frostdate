# FrostDate

Find your city's average first and last frost dates, growing season length, and get a frost-risk verdict before you plant. Free garden planner.

## Features
- 40-city US frost-date dataset with growing-season lengths
- Live planting countdown to your last spring frost
- Frost-risk verdict for any date you plan to plant
